# 🎮 坦克大战 (Tank Battle)

一个使用纯 HTML/CSS/JavaScript 开发的经典坦克大战网页游戏，基于 Canvas 渲染。

## 🎯 游戏特色

- **经典玩法**: 控制坦克消灭所有敌方坦克即可过关
- **多种地形**: 砖墙（可摧毁）、钢铁（不可摧毁）
- **道具系统**: ⚡加速、🔥速射、🛡️护盾、❤️额外生命
- **关卡递增**: 每关敌人数量和速度逐步提升
- **粒子特效**: 爆炸粒子效果
- **小地图**: 右下角实时小地图
- **移动端支持**: 触屏虚拟摇杆和射击按钮
- **音效**: Web Audio API 生成的实时音效

## 🕹️ 操作方式

| 操作 | 键盘 | 移动端 |
|------|------|--------|
| 移动 | 方向键 / WASD | 虚拟方向键 |
| 射击 | 空格 / J / Enter | 射击按钮 |

## 🚀 快速开始

1. 克隆仓库:
```bash
git clone https://github.com/yangfangxinxxx-cyber/tank-battle.git
```

2. 直接用浏览器打开 `index.html` 即可开始游戏！

不需要任何构建工具或服务器。
